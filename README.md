Task List Web Application
This application is a basic task list tool which you can use to keep track of tasks you need to do, add a priority, and tick them off when completed or delete them from the list.
To run the program all you need to do is enter the name of your task in the box, select the priority (low, medium, high), and click submit. From there in your task list box you can click the complete button when you finish, as well as click the delete button to remove the task from your list.
